# Python-movie-ticket-calculator
A Python movie ticket calculator that calculates ticket prices based on age, seat type, membership, showtime, and additional charges.

## Concepts Practiced

- Variables
- User input
- Type conversion
- If/else statements
- Boolean conditions
- Logical operators
- Nested conditions
- Arithmetic operations
- String formatting
- Basic terminal formatting

## Note

This is an educational project created while learning Python.
